# 大電視 · 設計審查（Brutalism 方向）

> 方法：`ui-ux-pro-max` 規則庫（192 推理規則／119 UX guideline／交付 checklist）＋ 實測 DOM（`tests/audit.js`）。
> 量度環境：1194×834（iPad 橫度）、四個畫面全部量一次。
> 結論先行：**規則層面基本合格（觸控、對比、無 emoji icon 都過），唔合格嘅係「一致性」——四個畫面用四套視覺語言。**

---

## 一、實測數據

| 指標 | 主持台 | 結果 | 題庫 | 排行榜 | 主頁 |
|---|---|---|---|---|---|
| 觸控目標 < 44px | 0 | 0 | **4**（返回／重新載入／兩個 tab，37–38px） | 0 | **8**（presets 38px、checkbox 13px、input 41–43px） |
| 文字 < 12px | 0 | 1（`其餘名次` 12px） | 0 | 0 | 0 |
| 對比 < 4.5:1 | 0 | 0 | 0 | 0 | 0 |

| 圓角值 | 4 種（0 / 4px / 50% / 999px） | 3 種 | 3 種 | 3 種 | 3 種 |

---

## 二、發現（按嚴重度）

### P0 · 四個畫面四套語言（一致性）

| 畫面 | 現時語言 | 問題 |
|---|---|---|
| 主持台 | 極簡舞台：大字 + 2 icon + 2 掣 | 幾乎冇 UI |
| 主頁 | 表單面板：well / row / chips / stepper | 有卡、有框、有 chips |
| 題庫 | 純文字文件 | 冇卡、冇框，只有一個 textarea |
| 結果 | 冠軍色塊 + 名次表 | 大色塊 + 表格 |

同一件事（例如「一個可以撳嘅選項」）在四個畫面出現四種樣：chip（主頁）、tab（題庫）、按鈕（主持台）、pill（準備畫面）。**這就是你說不出的「唔對」。**

### P1 · 圓角／邊框／陰影三套規格並存

- 邊框同時有 `0px`（無邊）、`1px`（icon、tab）、`2px`（卡、輸入、CTA）
- 圓角同時有 `0`（表單）、`4px`（卡）、`999px`（chip/pill）、`50%`（icon）
- 陰影：CTA 用 `6px 6px 0 lime`、底部導航用 `0 -3px 0 ember`、其餘冇

Brutalism 要嘅係「一種邊、一種角、一種陰影」。

### P1 · 字階冇 scale

每個畫面 3–8 個字級，冇共用比例。主持台用 15/20/27/359，結果頁用 12→44 八級，主頁 12→24 七級。

### P2 · 觸控目標不足

- 主頁 presets 38×38、`#secInput` 41px、checkbox 13×13
- 題庫 tab 同「返回／重新載入」37–38px 高

規則：iOS 44pt、Android 48dp、WCAG 24 CSS px。我哋 38 係「差少少但唔合規」。

### P2 · ember 一屏出現兩次

主頁同時用 ember 做「已選 preset」同「開始遊戲」；結果頁冠軍塊同 CTA 都係 ember（已改描邊，但仍屬同一色系）。規則：**一屏一個 ember 焦點**。

### P3 · 小字低於 12px

結果頁 `其餘名次` 用 12px（邊界值）；主持台標籤 15px 反而偏大。標籤級應該固定一個值。

---

## 三、Brutalism 目標 token（建議）

| Token | 現時 | 改成 | 理由 |
|---|---|---|---|
| 邊框 | 0/1/2px | **一律 2px solid `--rule`** | 粗邊係 Brutalism 的骨架 |
| 圓角 | 0/4/999/50% | **卡・輸入・按鈕・chip = 0**；只有 icon 圓 = 50% | 去圓角，保留 icon 圓作唯一例外 |
| 陰影 | 3 種 | **一種**：`4px 4px 0 var(--accent-2)`，只給每屏唯一主動作 | 陰影 = 動作，不是裝飾 |
| 字階 | 3–8 級 | **4 級**：舞台 `clamp(48px,22vh,240px)`／標題 28／正文 15／標籤 12 | 少而穩定 |
| 間距 | 混亂 | **8 的倍數**：8 / 12 / 16 / 24 / 32 | 對齊節奏 |
| 顏色 | ember 兩用 | ember = 當前動作（每屏 1 個）；acid = 時間／成功／連線；其餘灰階 | 顏色有工作 |
| 觸控 | 38px | **全部 ≥ 44px** | 合規 |

---

## 四、修復順序（一次一屏）

1. **Token 層**：邊 2px、圓角 0、陰影一種、字階 4 級、間距 8 倍數 —— 改 CSS 變數，四屏即時一致
2. **主頁**：presets 38→44、checkbox 換 44 行高、chips 去圓角
3. **題庫**：tab 38→44、textarea 邊框跟 token
4. **結果**：`其餘名次` 12px 統一標籤級
5. **主持台**：已經最接近目標，只跟 token 微調（icon 圓保留）

每步量三個數：觸控 < 44 數量、字級種類、邊框寬度種類。
