# 字階與間距審核（ui-ux-pro-max）

> 觸發：使用者反映「標題及內文字大小很奇怪，有些是標題小文字大；元素之間留白不夠」。
> 依據 skill：`ui-ux-pro-max`（priority 6 Typography & Color、priority 2 Touch & Interaction、priority 5 Layout）。
> 量度方法：`getComputedStyle` 讀實際 px，非憑感覺。

---

## 一、Skill 規則（引用）

| 規則 | 內容 |
|---|---|
| Typography & Color（priority 6） | 內文基準 16px、line-height 1.5、唔可以有 <12px 內文、用語意顏色 token |
| Touch & Interaction（priority 2） | 觸控目標最少 44×44px、元素之間最少 8px |
| Layout & Responsive（priority 5） | 唔可以橫向捲動 |
| 字階建議（typography 資料庫） | 12 標籤 / 16 內文 / 22 小標題 / 32 區塊 / 40 H2 / 56 H1；權重 700 區塊標題、600 卡片標題、400 內文 |

## 七、明亮主題（2026-11-02）

由深色（#000 底）轉 Apple 明亮：分組底 `#F2F2F7`、卡／內容面 `#FFFFFF`、主文字 `#000`、次要文字 `rgba(60,60,67,.72)`、分隔線 `rgba(60,60,67,.18)`、填色 `rgba(118,118,128,.12)`。

| token | 深色 | 明亮 |
|---|---|---|
| --bg | #000000 | #F2F2F7 |
| --surface | #1C1C1E | #FFFFFF |
| --ink | #FFFFFF | #000000 |
| --ink-2 | rgba(235,235,245,.60) | rgba(60,60,67,.72) |
| --sep | rgba(84,84,88,.65) | rgba(60,60,67,.18) |
| --fill | rgba(118,118,128,.24) | rgba(118,118,128,.12) |
| 藍（填色／強調） | #0A84FF | #0071E3（白字 4.7:1，過 AA） |

其他調整：
- `color-scheme: light`（native 控件、選字、數字 spinner 跟明亮）
- 遊戲頁與準備畫面用 `--surface` 白底黑字（唔再全黑）

- 白字對比由 4.02:1 提升到 4.7:1（藍 #007AFF → #0071E3）

## 八、設定流程拆步（2026-11-02）

問題：首頁把所有設定塞在一張 sheet，流程被壓縮，冇空間做動效同儀式感。

### 新流程
1. **入口**（`#v-home`）— 大電視（clamp 76–168px）＋ 規則一句 ＋「開始」＋ 現況一行；背景有極淡藍色光暈，7 秒呼吸
2. **第一步：隊伍數量** — 巨型數字（clamp 84–180px）＋ 兩側圓形 − +；提示「最少 2 隊，最多 8 隊」
3. **第二步：隊名** — 自動欄數格（min 240px），進場自動聚焦第一個輸入框
4. **第三步：每回合時間** — 巨型秒數（142px）＋ 30／60／90／120 chips（選中藍底）
5. **底部固定**：現況摘要（N 隊 · N 秒 · N 題）＋ 主掣（繼續 / 開始遊戲）
6. **開始**：白光過場（240ms）→ 進遊戲

### 動效
- 每步 `translateX(56px)` + fade，`cubic-bezier(.32,.72,0,1)` 420ms；回上一步由左邊入
- 步內元素 rise 進場，四級延遲 40/100/160/220ms
- 進度點：現用 `transform:scale(1.55)`（唔動 width，避免 layout 抖）
- 入口標題、副題、掣、現況四段 rise，60/120/180/240ms
- `prefers-reduced-motion` 交由全域既有規則處理

### 鍵盤
- 設定頁：`Enter` = 下一步／開始，`Esc` = 上一步
- 遊戲頁：`空白鍵` = 開始／判對，`S` = 跳過，`Esc`/`P` = 暫停

### 驗證
- 入口與三步在 1194×834、834×1194、744×1133、1024×1366 全部無溢出
- 全流程實跑：入口 → 6 隊 → 改名（紅隊）→ 30 秒 → 開始 → 準備畫面顯示「第 1 隊，共 6 隊 / 紅隊」
- sloplint `0 FAIL`

### 追加（同日）
- **第四步：題目** — 巨型題數（`5 題`）＋「編輯題目」次掣（去 `/edit`）＋提示「一行一題，任何人皆可修改」；未連線時提示改「題目尚未連線，正在重試…」、主掣變「題目未連線」並禁用
- **進度改 4 步**，右上是 `n / 4`
- **開場儀式**：按「開始遊戲」→ 內容上飛淡出（200ms）→ 藍幕 `#0071E3` 由下方以圓形 clip-path 擴散（460ms）→ 白色「大電視」字標淡入（延遲 140ms）→ 700ms 時在幕後切到遊戲 → 860ms 藍幕淡出 → 1240ms 清乾淨
- **入口儀式**：按「開始」→ 標題放大到 1.06 並淡出 300ms → 進入第一步
- 數字／秒數變更時 `scale(1.07)` 彈一下（`pop` 340ms）

實測時間軸（ms / clip-path）：
0 → `circle(0%)`；221 → `0.23%`；332 → `25.5%`；444 → `106%`；664 → `152%`（全滿）；885 起 opacity 由 1 落到 0.01（1150 完成）；字標 opacity 0 → 1（332–664）。

### 開場改為舞台幕（2026-11-02，取代圓形藍幕）

問題：圓形 clip-path 藍幕「怪」—— origin 寫死、內容同幕同時動、收尾淡出像濾鏡閃、滿飽和藍太重。

現行做法：
- `.launch` 內兩塊 `.curtain`（各 50.4% 高），靜止時 `translateY(∓100%)` 收喺畫面外；加 `.closed` 就夾合
- 幕面用三層背景：底部／頂部 radial 光暈（`--curtain-glow`）＋ 56px pitch 軟身褶紋（`--fold-*` 四個色階）＋ `--curtain-deep → --blue-fill` 垂直漸變
- 幕上 `.vs`：左隊名、`VS`、右隊名，全白，`scale(.97) → 1` + 淡入
- 時間軸：160ms 幕合（460ms）→ 620ms VS 入 → 1900ms VS 出 → 1980ms 幕後切遊戲 → 2120ms 幕開（460ms）→ 2660ms 復位
- 加 `.done{transition:none}` 復位，避免反向動畫
- 幕合期間 `pointer-events:auto`，點幕即 `skipLaunch()`（清 timer、即刻切遊戲、幕快速開啟）

實測（ms）：幕 301 開始夾、753 合滿；VS 753 開始現、1056 完全不透明、1500 淡出；1650 切到 v-play；1760 開幕、2258 全開；2409 清乾淨（class 只餘 `launch`，`translateY(-420)`）。
