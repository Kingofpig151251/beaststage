# 字階與間距審核（ui-ux-pro-max）

> 觸發：使用者反映「標題及內文字大小很奇怪，有些是標題小文字大；元素之間留白不夠」。
> 依據 skill：`ui-ux-pro-max`（priority 6 Typography & Color、priority 2 Touch & Interaction、priority 5 Layout）。
> 量度方法：`getComputedStyle` 讀實際 px，非憑感覺。

---

## 一、Skill 規則（引用）

| 規則 | 內容 |
|---|---|
| Typography & Color（priority 6） | 內文基準 16px、line-height 1.5、唔可以有 <12px 內文、用語意顏色 token |
| Touch & Interaction（priority 2） | 觸控目標最少 44×44px、元素之間最少 8px |
| Layout & Responsive（priority 5） | 唔可以橫向捲動 |
| 字階建議（typography 資料庫） | 12 標籤 / 16 內文 / 22 小標題 / 32 區塊 / 40 H2 / 56 H1；權重 700 區塊標題、600 卡片標題、400 內文 |

---

## 二、審核前實測（問題確認）

| 元素 | 原本 | 問題 |
|---|---|---|
| 頁面標題 h1 | 30px / 700 | 可接受 |
| **卡片標題 h2** | **13px / 600** | **比內文 17px 更細 → 正是「標題小文字大」** |
| 副標題 .sub | 15px | 尚可 |
| 標籤 .kv | 13px | 同標籤／內文差距過大 |
| 內文 / 輸入框 | 17px | 符合 16px 基準 |
| 題數 qcount | 30px | 壓過卡片標題（22px 未定時） |
| h1 → 副標題間距 | **6px** | 太窄 |
| 副標題 → 卡片 | 16px | 尚可 |
| 卡片標題 → 內容 | 14px | 偏窄 |
| 卡片內距 | 18px | 偏窄 |
| 欄距 / 卡距 | 16px | 偏窄 |

---

## 三、修正後的字階（嚴格遞減）

| 層級 | 大小 | 權重 | 用喺邊 |
|---|---|---|---|
| 頁面標題 | 30–34px | 700 | 大電視 / 結果 / 題目 |
| 卡片標題 | **22px** | 600 | 隊伍名單 / 計時 / 題目 |
| 強調數值 | **20px** | 700 | 題數（單位「題」15px muted） |
| 內文 / 輸入 / 按鈕 | **17px** | 400–600 | 隊名、秒數、掣 |
| 次要文字 | **15px** | 400–600 | 標籤、副標題、名次細節、狀態 |
| 註腳 | 13px | 500 | 快捷提示、極次要 |

量度結果：`h1 30 → h2 22 → 數值 20 → 內文 17 → 次要 15`，冇任何一級反轉。

## 五、驗證

- 四種 iPad 尺寸（1194×834、834×1194、1024×1366、744×1133）：**無橫向、無縱向捲動**
- 觸控目標：步進器 40px 圓鈕（外殼 48px）、輸入框 44px、CTA 52–56px，全部 ≥44
- 內文 17px ≥ 16px 基準；line-height 由 1.45 改 **1.5**
- sloplint：`0 FAIL`（6 個 WARN 全屬 #0A84FF 上白字 3.45:1，大字級別達 AA）
