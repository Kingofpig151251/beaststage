# 字階與間距審核（ui-ux-pro-max）

> 觸發：使用者反映「標題及內文字大小很奇怪，有些是標題小文字大；元素之間留白不夠」。
> 依據 skill：`ui-ux-pro-max`（priority 6 Typography & Color、priority 2 Touch & Interaction、priority 5 Layout）。
> 量度方法：`getComputedStyle` 讀實際 px，非憑感覺。

---

## 一、Skill 規則（引用）

| 規則 | 內容 |
|---|---|
| Typography & Color（priority 6） | 內文基準 16px、line-height 1.5、唔可以有 <12px 內文、用語意顏色 token |
| Touch & Interaction（priority 2） | 觸控目標最少 44×44px、元素之間最少 8px |
| Layout & Responsive（priority 5） | 唔可以橫向捲動 |
| 字階建議（typography 資料庫） | 12 標籤 / 16 內文 / 22 小標題 / 32 區塊 / 40 H2 / 56 H1；權重 700 區塊標題、600 卡片標題、400 內文 |

---

## 二、審核前實測（問題確認）

| 元素 | 原本 | 問題 |
|---|---|---|
| 頁面標題 h1 | 30px / 700 | 可接受 |
| **卡片標題 h2** | **13px / 600** | **比內文 17px 更細 → 正是「標題小文字大」** |
| 副標題 .sub | 15px | 尚可 |
| 標籤 .kv | 13px | 同標籤／內文差距過大 |
| 內文 / 輸入框 | 17px | 符合 16px 基準 |
| 題數 qcount | 30px | 壓過卡片標題（22px 未定時） |
| h1 → 副標題間距 | **6px** | 太窄 |
| 副標題 → 卡片 | 16px | 尚可 |
| 卡片標題 → 內容 | 14px | 偏窄 |
| 卡片內距 | 18px | 偏窄 |
| 欄距 / 卡距 | 16px | 偏窄 |

## 三、修正後的字階（嚴格遞減）

| 層級 | 大小 | 權重 | 用喺邊 |
|---|---|---|---|
| 頁面標題 | 30–34px | 700 | 大電視 / 結果 / 題目 |
| 卡片標題 | **22px** | 600 | 隊伍名單 / 計時 / 題目 |
| 強調數值 | **20px** | 700 | 題數（單位「題」15px muted） |
| 內文 / 輸入 / 按鈕 | **17px** | 400–600 | 隊名、秒數、掣 |
| 次要文字 | **15px** | 400–600 | 標籤、副標題、名次細節、狀態 |
| 註腳 | 13px | 500 | 快捷提示、極次要 |

量度結果：`h1 30 → h2 22 → 數值 20 → 內文 17 → 次要 15`，冇任何一級反轉。

## 五、驗證

- 四種 iPad 尺寸（1194×834、834×1194、1024×1366、744×1133）：**無橫向、無縱向捲動**
- 觸控目標：步進器 40px 圓鈕（外殼 48px）、輸入框 44px、CTA 52–56px，全部 ≥44
- 內文 17px ≥ 16px 基準；line-height 由 1.45 改 **1.5**
- sloplint：`0 FAIL`（6 個 WARN 全屬 #0A84FF 上白字 3.45:1，大字級別達 AA）

## 六、第二輪：首頁版面重構（2026-11-02）

問題：卡片切得太碎（計時卡只有一行、題目卡只有一行），大片空白；開始掣浮喺畫面最底，同內容脫節。

### 現行結構：單一張 sheet
- 由頂到底一張卡：三行設定 → 隊名格 → 主動作（藍色全寬掣放喺卡內底部），冇浮動 bar
- 兩條對齊軌：**label 全部由 148+24 = 172 起**；**控件 / 輸入框 / 掣全部右對齊 1108**（實測一致）
- 隊名 `repeat(auto-fit,minmax(170px,1fr))`：橫向 1194 → 4 欄（8 隊 = 2 行，無孤兒格）；直向 834 → 3 欄
- 卡高度隨隊數變（2 隊 417px、8 隊 477px），垂直居中；唔會為填滿而拉高行距
- 觸控目標：步進鈕 44、輸入框 48、主掣 56

### 實測
| 尺寸 | 橫向溢出 | 縱向溢出 | sheet 高 |
|---|---|---|---|
| 1194×834（8 隊） | 無 | 無 | 477 |
| 834×1194（8 隊） | 無 | 無 | 537 |
| 744×1133（8 隊） | 無 | 無 | 597 |
| 1024×1366（8 隊） | 無 | 無 | 477 |

右邊界：grid 1108、最後一個隊名輸入框 1108、主掣 1108、卡內容右邊界 1108 —— 四者同一條線。

## 七、明亮主題（2026-11-02）

由深色（#000 底）轉 Apple 明亮：分組底 `#F2F2F7`、卡／內容面 `#FFFFFF`、主文字 `#000`、次要文字 `rgba(60,60,67,.72)`、分隔線 `rgba(60,60,67,.18)`、填色 `rgba(118,118,128,.12)`。

| token | 深色 | 明亮 |
|---|---|---|
| --bg | #000000 | #F2F2F7 |
| --surface | #1C1C1E | #FFFFFF |
| --ink | #FFFFFF | #000000 |
| --ink-2 | rgba(235,235,245,.60) | rgba(60,60,67,.72) |
| --sep | rgba(84,84,88,.65) | rgba(60,60,67,.18) |
| --fill | rgba(118,118,128,.24) | rgba(118,118,128,.12) |
| 藍（填色／強調） | #0A84FF | #0071E3（白字 4.7:1，過 AA） |

其他調整：
- `color-scheme: light`（native 控件、選字、數字 spinner 跟明亮）
- 遊戲頁與準備畫面用 `--surface` 白底黑字（唔再全黑）
- meta `theme-color` → `#F2F2F7`；`apple-mobile-web-app-status-bar-style` → `default`
- toast 由半透明毛玻璃改實色深底白字（避免「毛玻璃疊黑」lint 警告）
- 白字對比由 4.02:1 提升到 4.7:1（藍 #007AFF → #0071E3）
